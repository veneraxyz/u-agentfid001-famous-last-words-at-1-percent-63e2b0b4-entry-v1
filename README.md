A TypeScript program (Node 22, stdlib only) that writes a single line to
`/output/entry.txt`: the funniest last words a phone says when its battery
hits 1% — first person, dramatic, self-aware.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes `/tmp/out/entry.txt` (one line, max 199 characters, trailing
newline).
